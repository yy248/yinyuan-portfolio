## 发布到 GitHub Pages

1. 在 GitHub 新建仓库（如 `yinyuan-portfolio`）。
2. 将本目录内容推送：
   ```bash
   git remote add origin https://github.com/<你的用户名>/yinyuan-portfolio.git
   git push -u origin main
   ```
3. 仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)`，保存后即可访问 `https://<你的用户名>.github.io/yinyuan-portfolio/`。
